# Third-party components

This workspace contains upstream projects and derived code, including FAST-LIO,
Livox ROS Driver 2, Robosense/RSLidar SDK code, RViz plugins, Open3D integration,
PCL, Eigen, CasADi, IPOPT, and ROS packages.

Each component remains subject to its own license and notice files. The
aggregate repository does not replace those licenses. Some package manifests
in the historical code still contain `TODO` license fields; resolve ownership
and licensing before distributing binaries commercially.

The Unitree Go2 Python SDK and M20 platform software are external runtime
dependencies and are not made portable by this repository. Confirm their CPU,
OS, device, and redistribution terms separately.
