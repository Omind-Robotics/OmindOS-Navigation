# 移动双臂机器人控制接口边界

2026-10-08 用户明确的实机接入安排：

| 子系统 | 我们调用的接口 | 下级控制职责 |
| --- | --- | --- |
| 左机械臂 | 厂家机械臂 SDK，独立连接/会话 | 机械臂控制器驱动内部各关节电机 |
| 右机械臂 | 厂家机械臂 SDK，独立连接/会话 | 机械臂控制器驱动内部各关节电机 |
| 移动底盘 | 厂家底盘 SDK | 底盘控制器分配并执行各轮运动 |
| 腰部俯仰关节 | 独立驱动器接口 | 我们按驱动器支持的方式下发腰关节目标并读取反馈 |

用户口述的腰部驱动器品牌转写为“elbow”；尚未核实型号、拼写或通信接口，不据此确定品牌或协议。

随后用户确认机械臂型号为 RM75，并提供厂家产品页 https://www.realman-robotics.cn/cn/products/rm75.html 。该页列出标准版与六维力版，不能仅凭这一链接确定用户实机的具体子型号。现有参考 URDF 为 RM75-B。

厂家 SDK 入口：https://develop.realman-robotics.com/en/robot/download/redevelopment/ ，官方推荐 RM_API2（https://github.com/RealManRobot/RM_API2）；实际 SDK 版本须与控制器版本对应。当前只记录接入依据，并未加载 SDK、连接设备或发送指令。

客户期望在同一面板填写机械参数和通信配置，保存后按配置加载，而非修改源码。通信配置应按已适配的设备型号/SDK 显示所需字段，左右臂分别保存各自连接信息；不能仅凭填写任意协议名称就自动获得兼容性。当前发行仅含 URDF/电机参数保存，尚未实现通信配置面板或 SDK 接入。

上层工作台统一表达关节目标与底盘运动意图，硬件适配层按子系统调用厂家 SDK 或腰部驱动器。机械臂关节点动也须经该臂 SDK 执行；不假定我们直接访问臂内电机。底盘实机运动经底盘接口执行，不把预览中的四轮轮速直接当作下发接口。两臂独立 SDK 连接不意味着已经具备同步执行能力。

ROS 是可选集成方式，不是本工作台或这一硬件边界的必需依赖。具体角度单位、关节编号、目标形式、反馈、停止行为与同步能力，按各厂家 SDK 的实际文档确认。

当前 0.2.0-preview.3 仍只运行本机运动学预览，没有连接上述 SDK 或腰部驱动器，没有发送实机命令。软件急停与复位也仅作用于工作台，不能视作已实现实机急停链路。四轮差速是预览参考模型，不能据此推断实机底盘轮型。
