# 机器人三维调参工作台（运动学预览版）

客户通过界面导入 URDF、编辑结构与电机参数、试运行和保存配置，无需修改算法代码。工作台与参数 API 共用不可覆盖的配置版本。

当前优先交付电脑端工作台，在运行本机服务的电脑浏览器中使用。手机 App 安排在后续阶段；当前没有 APK、移动端安装包或手机远程连接入口。

## 启动

在仓库根目录执行（Python 3.10+，仅标准库）：

```bash
python3 scripts/robot_workbench.py --store ./robot-configurations --port 8085
```

浏览器打开 `http://127.0.0.1:8085/`。服务及资源全部在本机，无 CDN、npm 构建或 ROS 依赖。不要与旧参数服务占用同一端口同时运行；工作台已经包含注册、读取 API。服务仅监听回环地址并检查 Host/Origin；这不是公网登录或多租户服务。

## 使用流程

1. 导入 `.urdf` / `.xml`，或者已经包含 URDF 和电机声明的完整配置 `.json`（API 请求格式）。单独导入 URDF 可立即查看结构，但电机与传动参数留空，需按实际设备补齐后才能试运行和保存。
2. 从下拉菜单或三维视图选择关节、连杆。关节页编辑转轴、相对父连杆的位置/旋转、限位、阻尼/摩擦、电机型号、传动比、方向、零点和关节侧力矩/速度上限。连杆页编辑质量、质心、惯量及基本外形尺寸。
3. 在左侧底部点击“将以上参数写入程序”，完整校验后保存版本并设为工作台当前配置；重新打开页面或重启服务后自动加载。未写入的修改也可临时预览。该按钮写入运行配置，不修改算法源码，也不激活真机控制器。
4. 右侧选择活动关节，点击 `−0.1°` / `+0.1°`，仅让该关节从当前显示角度点动，其他关节和底盘位姿保持不变。不能越过关节限位，点动时长受驱动速度限制。
5. 设定振幅（°）、周期（秒）及周期数，点击“左臂正弦”“右臂正弦”“双臂正弦”或“全身正弦”。围绕当前姿态同相往复，完整周期结束后回到起点；未选关节保持不变。
6. 展开右侧“整机目标姿态”，可调整腰部 pitch、左右夹爪和底盘 X/Y/转向。设定运行时长，点击“试一下”，从零位生成平滑目标轨迹；可以中途停止或点击“姿态归零”。
7. 查看各关节的静态重力保持力矩。超出已填写力矩上限时标红；轨迹峰值速度超出上限时拒绝运行并提示最短时长或周期。
8. “保存新版本”仅保存历史版本，不切换程序当前配置；按旧编号读取后可再次“写入程序”，切换回旧配置。也可导出完整 JSON。

## 急停与正弦范围

右侧顶部红色“急停”按钮和 `Esc` 会立即停止本页播放并锁定点动、正弦、目标试跑和姿态滑块。它独立于计算请求，不会等待计算完成；较早的返回结果不能重新启动运动。服务端同时锁定三个运动接口，返回 HTTP 423；同一服务的其他页面会在状态轮询后停止。刷新页面仍保持服务的急停状态。点击“解除”仅解锁，必须重新启动动作，不自动续播；解除请求会检查状态版本，避免覆盖刚发生的新急停。

“停止当前运动”只停止本次播放并保持当前姿态；服务连接中断时，本页也停止并要求恢复连接后手动解除。当前急停是**工作台软件联锁**，没有安全等级认证，不能替代真机硬件急停。服务重启后没有运行任务，也不会自动播放；急停锁存状态仅保留在服务进程内。

正弦公式为 `q(t)=q0+A sin(2πt/T)`。振幅范围 `(0,90]°`，周期 0.5–30 秒，1–10 个周期，总时长不超过 60 秒。后端按 `2πA/T` 检查峰值角速度；限位余量不足时缩小该关节振幅并显示实际值，处于限位的关节振幅可能为零。若全部所选关节都无法运动则拒绝启动。每周期至少 24 个采样间隔、包含正负峰值，整段最多 361 帧。起止速度未做真机轨迹整形，只用于运动学预览。

单臂按 `left_` / `right_` 前缀识别，并排除轮轴、手指、夹爪、腰和头部；示例每臂包含肩、肘、腕三个关节，双臂共六个。导入命名不匹配的模型时，相应单臂按钮禁用。“全身”包含全部活动旋转关节（示例含腰部、双臂、手指、轮轴），固定头部随躯干运动；**底盘平面位姿保持不变**，轮轴摆动不代表地面行驶。

内置模型为合成的移动双臂教学结构：20 个连杆、16 个活动关节，包括双臂 6 轴、腰部 yaw/pitch 2 轴、两组双指夹爪的 4 个铰接轴，以及 4 个轮轴；头部通过固定颈座连接躯干，随腰部运动。腰部 pitch 绕 Y 轴俯仰，范围 ±0.55 rad；夹爪由两个反向转轴同步张开，0% 对应合拢角，100% 对应张开角。头部带面罩和双镜头外观（没有接入相机功能）；夹爪外形包含安装法兰、电机壳、铰接指节、弯折金属手指、橡胶夹持面和防滑纹。夹爪快捷控制按两指各自的上下限映射；单指也可以独立调节。它**不是 RM75-B 15 自由度整机，也不是 MEVIUS2 原版模型**，型号、尺寸、减速比、质量与近似惯量仅用于示例。可用 `python3 scripts/build_workbench_demo.py` 重建示例 JSON。

底盘 X/Y 使用世界坐标（m），转向输入为角度（°，接口为 rad）。这只是给定平面位姿的运动学预览：不从车轮转速推导移动，不自动联动轮轴，也没有导航、里程计或轮地接触求解。移动预览采用 0.5 m/s、0.8 rad/s 的节奏上限，**不是实际底盘能力参数**。界面与接口限制 X/Y 各 ±5 m、转向 ±360°。导入其他模型后，按关节名称匹配腰部和夹爪快捷控件；不匹配的控件隐藏。

## 参数真正影响哪些结果

| 修改 | 当前计算/显示效果 |
| --- | --- |
| 关节 origin、axis、目标角 | 改变整个下游连杆的三维位置和姿态 |
| 底盘 X/Y/转向目标 | 变换整棵连杆树；试跑时同步插值给定基座位姿 |
| 连杆质量、质心 | 改变静态重力保持力矩 |
| 关节速度上限 | 约束平滑轨迹的最短时长 |
| 输出侧力矩上限 | 与采样点静态重力保持力矩对比并提示超限 |
| 减速比、方向、零点 | 按既有 API 约定换算各帧电机轴位置 |
| visual 的尺寸和偏移 | 更新显示外形，不自动改变关节连接距离 |
| 惯量、阻尼、摩擦、电机型号 | 校验并保存；当前不执行惯性动力学积分或驱动适配 |

一般 URDF 没有统一的“腿长”字段。改变机械连接距离要编辑对应 joint origin；visual 长度、碰撞几何、质心和惯量应按新结构分别更新。工作台不会猜测 CAD 设计约束或自动把外形尺寸当成机构尺寸。

## 计算约定与边界

- 支持树形结构的 fixed、revolute、continuous 关节；不支持 mimic、prismatic、自由浮动基座动力学、闭环机构自动转换。给定基座位姿独立于 URDF 关节树，不增加虚拟驱动关节。最多 128 个连杆、127 个关节，每连杆最多 16 个 visual。
- 位姿为 `T_child = T_parent × T_origin × Rot(axis, q)`，RPY 使用 `Rz(yaw) Ry(pitch) Rx(roll)`；长度 m，角度 rad。
- 轨迹为 `q(u) = q0 + (q1-q0)(3u²-2u³)`，起始角为零位按限位约束，峰值速度为 `1.5|q1-q0|/duration`。最多输出 181 帧；最长 60 秒。continuous 关节按给定角度差插值，不自动选择最短环绕路径。
- 静态重力估计：每帧把基座视为受支撑，世界重力 `[0,0,-9.80665] m/s²`，将下游所有连杆的质心重力矩投影到关节轴并取保持力矩。基座平移或水平转向不改变静态重力力矩。显示峰值来自离散采样，不是整段轨迹的连续极值证明。
- 无碰撞检测、接触求解、地面约束、步态、平衡、摩擦/加速度负载或外部载荷计算。根基座支撑力与轮地驱动力未求解。这些结果不代表整机稳定、轨迹无碰撞或真机可执行。
- box、cylinder、sphere 默认以实体材质、灯光和软阴影显示，可切换线框；支持 URDF 内联或命名 material 的 RGBA 颜色。box 边缘倒角和关节选择标记仅用于显示，不改变运动学或保存的模型参数。WebGL 不可用时回退兼容线框。mesh 不自动下载/读取外部资源，会明确提示并显示关节骨架。保存保留 URDF 里的 mesh 引用和其他未编辑节点。
- 注册继续使用原 API 的完整质量/惯量和驱动参数校验；缺少物理属性的 URDF 可以查看结构，但不能作为完整机器人配置保存。
- “真机执行”未接入；程序不会发送 ROS/CAN/电机命令。`runtime_applied`、`hardware_validated` 始终为 false。

## 新增接口

| 方法/路径 | 请求 | 响应 |
| --- | --- | --- |
| `POST /v1/robot-model` | `urdf_xml`，可选 `positions`（关节名→rad）、`base_pose`（`x_m/y_m/yaw_rad`） | 解析模型与真实计算位姿；不保存 |
| `POST /v1/robot-preview` | `profile`（完整参数 API 请求），可选 `start`、`target`、`duration_s`、`base_start`、`base_target` | 轨迹帧、基座位姿、连杆变换、重力负载、电机轴位置、关节/基座峰值速度和范围说明 |
| `POST /v1/robot-jog` | `profile`，`joint`、`direction`（±1），可选 `start`、`base_pose` | 固定 ±0.1° 单关节点动轨迹 |
| `POST /v1/robot-sine` | `profile`，`joints`（活动关节名列表），可选 `start`、`amplitude_deg`、`period_s`、`cycles`、`base_pose` | 正弦轨迹、实际振幅、限幅关节、峰值速度与静态重力 |
| `POST /v1/workbench-active-profile` | 完整参数配置 | 保存版本并原子替换当前配置指针；`workbench_applied=true`，真机 `runtime_applied=false` |
| `GET /v1/workbench-active-profile` | 无 | 当前配置、版本和急停状态；尚未写入时 `profile=null` |
| `GET /v1/workbench-state` | 无 | 当前配置编号、急停状态和 `motion_epoch` |
| `POST /v1/workbench-stop` | `engaged=true`；解除为 `engaged=false` 且提供 `expected_epoch` | 急停锁存/手动解除后的状态 |
| `POST /v1/robot-profiles` | 既有完整参数请求 | 不可覆盖的配置编号 |
| `GET /v1/robot-profiles/{id}` | 无 | 校验摘要后返回完整原配置 |

所有写请求使用 `Content-Type: application/json`，请求体上限 2 MiB。新增基座位姿字段省略时为零位，既有调用保持兼容。基座 X/Y/yaw 与关节角使用相同的 smoothstep 插值，不自动取转向最短路径。编辑器中的关节目标、夹爪开合、底盘目标与播放时长是本次试跑设置，不属于已保存的硬件配置；配置保存包含机器人 ID、URDF 和驱动参数。

三个运动接口省略 `profile` 时，使用已经写入的程序当前配置。计算前后都检查急停与状态版本，防止旧计算结果越过新的急停或配置切换。配置指针保存于服务 `--store` 目录的 `workbench-active.json`，被引用的历史版本继续保留；非法写入不会替换旧配置。

## 验证

```bash
python3 -m unittest discover -s tests -v
node --check web/robot-workbench/workbench.js
```

测试包含解析解对照（摆杆端点及重力保持力矩）、质量和连接距离修改后的计算变化、RPY 与非单位转轴、速度/关节限位、传动换算、超限提示、真实本机 HTTP 试跑/保存/读取及同源限制。桌面/手机浏览器检查见同目录 validation 记录。
