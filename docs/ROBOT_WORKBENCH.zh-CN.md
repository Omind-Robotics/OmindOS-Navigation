# 机器人三维调参工作台（运动学预览版）

客户通过界面导入 URDF、编辑结构与电机参数、试运行和保存配置，无需修改算法代码。工作台与参数 API 共用不可覆盖的配置版本。

当前优先交付电脑端工作台，在运行本机服务的电脑浏览器中使用。手机 App 安排在后续阶段；当前没有 APK、移动端安装包或手机远程连接入口。

## 启动

在仓库根目录执行（Python 3.10+，仅标准库）：

```bash
python3 scripts/robot_workbench.py --store ./robot-configurations --port 8085
```

浏览器打开 `http://127.0.0.1:8085/`。服务及资源全部在本机，无 CDN、npm 构建或 ROS 依赖。不要与旧参数服务占用同一端口同时运行；工作台已经包含注册、读取 API。服务仅监听回环地址并检查 Host/Origin；这不是公网登录或多租户服务。

## 使用流程

1. 导入 `.urdf` / `.xml`，或者已经包含 URDF 和电机声明的完整配置 `.json`（API 请求格式）。单独导入 URDF 可立即查看结构，但电机与传动参数留空，需按实际设备补齐后才能试运行和保存。
2. 从下拉菜单或三维视图选择关节、连杆。关节页编辑转轴、相对父连杆的位置/旋转、限位、阻尼/摩擦、电机型号、传动比、方向、零点和关节侧力矩/速度上限。连杆页编辑质量、质心、惯量及基本外形尺寸。
3. 在左侧底部点击“将以上参数写入程序”，完整校验后保存版本并设为工作台当前配置；重新打开页面或重启服务后自动加载。未写入的修改也可临时预览。该按钮写入运行配置，不修改算法源码，也不激活真机控制器。
4. 右侧选择活动关节，点击 `−0.1°` / `+0.1°`，仅让该关节从当前显示角度点动，其他关节和底盘位姿保持不变。不能越过关节限位，点动时长受驱动速度限制。
5. 设定振幅（°）、周期（秒）及周期数，点击“左臂正弦”“右臂正弦”“双臂正弦”或“全身正弦”。围绕当前姿态同相往复，完整周期结束后回到起点；未选关节保持不变。
6. 展开右侧“整机目标姿态”，可调整腰部 pitch、左右夹爪和底盘 X/Y/转向。设定运行时长，点击“试一下”，从零位生成平滑目标轨迹；可以中途停止或点击“姿态归零”。
7. 查看各关节的静态重力保持力矩。超出已填写力矩上限时标红；轨迹峰值速度超出上限时拒绝运行并提示最短时长或周期。
8. “保存新版本”仅保存历史版本，不切换程序当前配置；按旧编号读取后可再次“写入程序”，切换回旧配置。也可导出完整 JSON。

## 设备通信：先保存，连接时再选择

左侧“设备通信”可分别设置左机械臂、右机械臂、腰部和底盘。每项默认“待选择”，地址、端口和总线参数可以留空，随“将以上参数写入程序”或“保存新版本”一起保存。切换方式保留之前填写的参数；刷新、重启、导出完整配置和重新导入均保留。仅浏览不同设备不会修改旧配置或其版本编号。

| 设备预设 | 可选方式 | 参数示例 |
| --- | --- | --- |
| 左、右 RM75，分别设置 | 厂家 SDK/TCP、JSON/TCP、JSON/RS-485、JSON/RS232-USB（基础系列） | 各自地址/串口、端口、控制器版本、SDK 版本；串口选项须按控制器版本确认 |
| Elmo Gold DBTwitter 腰部 | CANopen、EtherCAT、RS-232 | CAN 接口/节点/速率，主站网卡/从站/ESI，串口/波特率/电平 |
| DT-01 Pro 底盘 | RS-232、MQTT、Modbus 扩展待确认 | 串口参数，Broker/主题，传输方式/站号/寄存器表版本 |

这些是**配置选项，所有真机驱动均未接入**。选择、保存、导入配置不打开网络、串口或总线，不加载 SDK，也不触发运动；急停保持锁定。客户选择型号和参数后，仍需要对应适配器及实机连接验收。字段留空表示待确认，不使用猜测的设备地址或端口；填写非空值后会进行类型和范围检查，未选中的已保存选项也要通过检查。当前不保存密码、令牌或加载 ESI 文件，ESI/协议字段仅作为名称和版本记录。

DT-01 Pro 资料写明双轮差速驱动、前后脚轮，轮径 140 mm、轮距 357 mm；RS-232 为底盘控制方式，MQTT 为导航接口，Modbus 仅注明可扩展。设备通信预设不会自动改写当前四轮参考 URDF 或改变仿真轮型。Elmo 安装手册同时涵盖 CANopen、EtherCAT 版本及不同串口电平，不能据手册名称判断手中设备的具体版本。

依据：用户提供的《DT-01 Pro 导航车.pdf》（产品介绍及参数页）、《MAN-G-DBTWI20240903.pdf》（型号编码及通信选项）；RM75 接口参考[厂家 JSON 协议文档](https://develop.realman-robotics.com/robot4th/json/getStartedJson/)及[控制器/API 版本对应关系](https://develop.realman-robotics.com/robot/releaseNotes/releaseNotes/)。资料用于列出待选项，不表示已确认客户控制器代际。

## 急停与正弦范围

右侧顶部红色“急停”按钮和 `Esc` 会立即停止本页播放并锁定点动、正弦、目标试跑和姿态滑块。它独立于计算请求，不会等待计算完成；较早的返回结果不能重新启动运动。服务端同时锁定五个运动接口（含底盘试跑和协同序列），返回 HTTP 423；同一服务的其他页面会在状态轮询后停止。刷新页面仍保持服务的急停状态。点击急停旁的“复位”仅解除急停锁定，不改变当前姿态、不归零，必须重新启动动作，不自动续播；“姿态归零”是另一项独立操作；解除请求会检查状态版本，避免覆盖刚发生的新急停。

“停止当前运动”只停止本次播放并保持当前姿态；服务连接中断时，本页也停止并要求恢复连接后手动复位。当前急停是**工作台软件联锁**，没有安全等级认证，不能替代真机硬件急停。服务重启后没有运行任务，也不会自动播放；急停锁存状态仅保留在服务进程内。

正弦公式为 `q(t)=q0+A sin(2πt/T)`。振幅范围 `(0,90]°`，周期 0.5–30 秒，1–10 个周期，总时长不超过 60 秒。后端按 `2πA/T` 检查峰值角速度；限位余量不足时缩小该关节振幅并显示实际值，处于限位的关节振幅可能为零。若全部所选关节都无法运动则拒绝启动。每周期至少 24 个采样间隔、包含正负峰值，整段最多 361 帧。起止速度未做真机轨迹整形，只用于运动学预览。

单臂按 `left_` / `right_` 前缀识别，并排除轮轴、手指、夹爪、腰和头部；当前参考模型左右臂各七轴，双臂共十四轴。导入命名不匹配的模型时，相应单臂按钮禁用。“全身”只包含主体关节，当前为双臂十四轴加腰部 pitch 一轴，共十五轴。夹爪、轮轴和底盘平面位姿保持不变；点动下拉菜单按主体关节、夹爪、底盘轮轴分组，辅助关节仍可单独点动。

内置模型使用两份 RM75-B 七轴 URDF：保留厂家关节连接、转轴、位置限位、质量和惯量，出处与许可证见 `config/robot_models/realman_rm75/NOTICE.md`。界面显示十五个主体关节；URDF 另外包含四个夹爪铰接轴和四个轮轴，共二十三个活动旋转关节、三十二个连杆。头部固定安装，随腰部 pitch 运动，没有额外的腰部 yaw。两臂参考安装点为世界坐标 `[0.10, ±0.10, 1.06]`，腰部参考轴心 `[0.10, 0, 0.66]`。客户可按硬件编辑 URDF 的安装尺寸、机构、质量/惯量，以及驱动与通信参数，并保存独立配置；内置值是参考配置。

手臂外形加载厂家 RM75-B 的 8 个原始 STL，左右臂共 16 个实例，保持厂家 visual/collision 原点和网格单位；资源来源与原始 blob 哈希见 meshes/PROVENANCE.json。机身、头部、夹爪、轮子及电机/减速器声明仍为参考值，不代表真实整机参数或实机验收。夹爪由两个反向转轴同步开合，范围 0–0.65 rad；腰部 pitch 范围 ±0.55 rad。当前仍是运动学与静态重力预览。可用 `python3 scripts/build_workbench_demo.py` 重建配置；已经保存的旧配置不会被自动覆盖，使用“加载双七轴移动机器人”后再点击“将以上参数写入程序”切换到新版。

“整机目标姿态”里的底盘 X/Y 使用世界坐标（m），转向输入为角度（°，接口为 rad）。这只是给定平面位姿的运动学预览：不从车轮转速推导移动，不自动联动轮轴，也没有导航、里程计或轮地接触求解。移动预览采用 0.5 m/s、0.8 rad/s 的节奏上限，**不是实际底盘能力参数**。界面与接口限制 X/Y 各 ±5 m、转向 ±360°。导入其他模型后，按关节名称匹配腰部和夹爪快捷控件；不匹配的控件隐藏。

## 四轮底盘试跑

右侧独立提供前进、后退、左转、右转和停车。当前示例明确使用**四轮差速参考模型**，实机轮型尚未确认，不支持侧移；这不是万向轮或麦克纳姆底盘的实机适配。轮距从四个轮轴的 URDF 安装位置读取，轮径从各轮连杆第一个圆柱外形读取。默认半径 0.10 m、轮距 0.59 m。修改这些参数会改变计算轮速，并随“将以上参数写入程序”保留。

线速度和角速度是峰值。每次运行 0.5–10 秒，使用 `g(t)=(1−cos(2πt/T))/2` 平滑起停，因此总行程为 `峰值线速度×T/2`，总转角为 `峰值角速度×T/2`。到时自动停车。默认 0.15 m/s、3 秒前进 0.225 m；默认 20°/s、3 秒转向 30°。每帧同时更新四轮转角、各轮 rpm 和底盘位姿；双臂、腰部及夹爪保持当前关节角。后续试跑从停止位置继续。

差速关系是左右轮切向速度 `v∓ωb/2`，分别除以该轮半径，并按 URDF 轮轴方向换算关节角速度。由各轮角速度恢复左右侧平均切向速度，再解析积分底盘 SE(2) 位姿，支持非零初始朝向和接口中的圆弧指令。参考公式见 [ros2_control 差速控制器](https://control.ros.org/rolling/doc/ros2_controllers/diff_drive_controller/doc/userdoc.html)。四轮转向可能产生的侧滑、接触力和真实里程计误差未求解。

峰值线速度限制为 ±0.5 m/s、角速度 ±0.8 rad/s，同时检查四个轮轴各自的驱动速度上限；任一超限或超出预览范围就拒绝整段试跑。“停车”取消当前播放或等待中的结果，保持轮角和底盘位置；全局“急停”还会锁住全部运动接口。“复位”不归零、不自动续跑。

URDF 中的工作台扩展 `omindos_base` 显式声明 `type="four_wheel_differential"`，以及 `left_front/right_front/left_rear/right_rear` 四个轮轴名称。没有该声明的导入模型不会自动猜测轮型。当前参考求解器要求 continuous 轮轴直接连接根连杆、与底盘 Y 轴平行，左右安装位置对称、同侧前后轮 Y 相同，首个轮胎圆柱与轮轴同心同轴；不满足时需先修正模型。单轮 ±0.1° 点动仍是独立关节检查，不驱动底盘行走。

## MDA1 三维交互验证分支

参考照片仅用于机身表面配色与固定头部外观；安装点、关节数量与转轴保持既有 URDF。照片中的灵巧手未建模，本分支仍保留原双指夹爪。四轮差速参考底盘并未替换为 DT-01 Pro 的双驱动轮加脚轮机构。

“播放连续演示”从当前姿态运行 35 秒参考轨迹：双臂接近、对齐、夹爪同步合拢、抬升、底盘圆弧行进时的双臂调整、左右夹爪独立张开、协同回位。该功能由本机 `/v1/robot-sequence` 计算，不调用电机；修改关节结构后，内置示例会拒绝运行，普通参数编辑和试跑继续可用。每段关节使用五次插值，端点速度和加速度为零，按 `1.875|Δq|/duration` 校验峰值速度；轮速采用既有四轮参考求解器的余弦起停。前端按真实时间戳选取帧，在插值角度处重新计算 URDF FK，不直接线性混合各连杆位置。

视图增加底盘跟随、左右夹爪特写、工具轨迹和扩大视图。扩大视图保留急停按钮，Esc 继续有效；复位仍必须明确操作，不自动续播。通信配置和参数版本接口保持原有语义。

`python3 scripts/check_mda1_mujoco.py --output mujoco-check.json` 是可选的离线导入检查，需要另外安装 MuJoCo 和 NumPy。已实际检查 23 自由度 URDF 编译、惯量正定和三角不等式、10 组姿态静态重力对照、每姿态 2 秒理想重力补偿积分。该检查固定根基座并禁用接触，不包含真实执行器，不代表整机轮地、抓取、自碰撞或平衡动力学验收。MuJoCo 未接入本工作台播放循环，也未打入桌面安装包。

可验证结果与缺失参数见 [MDA1 分支验收](validation/mda1-interactive-20261009.md)。本分支没有更新 preview.7 标签或公开安装包。

## 参数真正影响哪些结果

| 修改 | 当前计算/显示效果 |
| --- | --- |
| 关节 origin、axis、目标角 | 改变整个下游连杆的三维位置和姿态 |
| 底盘 X/Y/转向目标 | 变换整棵连杆树；试跑时同步插值给定基座位姿 |
| 连杆质量、质心 | 改变静态重力保持力矩 |
| 关节速度上限 | 约束平滑轨迹的最短时长 |
| 输出侧力矩上限 | 与采样点静态重力保持力矩对比并提示超限 |
| 减速比、方向、零点 | 按既有 API 约定换算各帧电机轴位置 |
| visual 的尺寸和偏移 | 更新显示外形；已声明四轮底盘的首个轮胎圆柱半径同时用于轮速计算 |
| 惯量、阻尼、摩擦、电机型号 | 校验并保存；当前不执行惯性动力学积分或驱动适配 |

一般 URDF 没有统一的“腿长”字段。改变机械连接距离要编辑对应 joint origin；visual 长度、碰撞几何、质心和惯量应按新结构分别更新。工作台不会猜测 CAD 设计约束或自动把外形尺寸当成机构尺寸。

## 计算约定与边界

- 支持树形结构的 fixed、revolute、continuous 关节；不支持 mimic、prismatic、自由浮动基座动力学、闭环机构自动转换。给定基座位姿独立于 URDF 关节树，不增加虚拟驱动关节。最多 128 个连杆、127 个关节，每连杆最多 16 个 visual。
- 位姿为 `T_child = T_parent × T_origin × Rot(axis, q)`，RPY 使用 `Rz(yaw) Ry(pitch) Rx(roll)`；长度 m，角度 rad。
- 轨迹为 `q(u) = q0 + (q1-q0)(3u²-2u³)`，起始角为零位按限位约束，峰值速度为 `1.5|q1-q0|/duration`。最多输出 181 帧；最长 60 秒。continuous 关节按给定角度差插值，不自动选择最短环绕路径。
- 静态重力估计：每帧把基座视为受支撑，世界重力 `[0,0,-9.80665] m/s²`，将下游所有连杆的质心重力矩投影到关节轴并取保持力矩。基座平移或水平转向不改变静态重力力矩。显示峰值来自离散采样，不是整段轨迹的连续极值证明。
- 无碰撞检测、接触求解、地面约束、步态、平衡、摩擦/加速度负载或外部载荷计算。根基座支撑力与轮地驱动力未求解。这些结果不代表整机稳定、轨迹无碰撞或真机可执行。
- box、cylinder、sphere 默认以实体材质、灯光和软阴影显示，可切换线框；支持 URDF 内联或命名 material 的 RGBA 颜色。box 边缘倒角和关节选择标记仅用于显示，不改变运动学或保存的模型参数。WebGL 不可用时回退兼容线框。mesh 仅从显式许可的本地 RM75-B 资源目录加载，支持 visual 的 transform 和 scale；未知 package、文件路径或网络 URL 会提示并显示骨架，不自动下载或读取外部资源。保存保留 URDF 里的 mesh 引用和其他未编辑节点。
- 注册继续使用原 API 的完整质量/惯量和驱动参数校验；缺少物理属性的 URDF 可以查看结构，但不能作为完整机器人配置保存。
- “真机执行”未接入；程序不会发送 ROS/CAN/电机命令。`runtime_applied`、`hardware_validated` 始终为 false。

| 方法/路径 | 请求 | 响应 |
| --- | --- | --- |

| `POST /v1/robot-preview` | `profile`（完整参数 API 请求），可选 `start`、`target`、`duration_s`、`base_start`、`base_target` | 轨迹帧、基座位姿、连杆变换、重力负载、电机轴位置、关节/基座峰值速度和范围说明 |
| `POST /v1/robot-jog` | `profile`，`joint`、`direction`（±1），可选 `start`、`base_pose` | 固定 ±0.1° 单关节点动轨迹 |
| `POST /v1/robot-wheel-base` | `profile`，可选 `start`、`base_pose`、`linear_m_s`、`angular_rad_s`、`duration_s` | 四轮角度、轮速、底盘位姿及平滑起停帧；受统一急停约束 |
| `POST /v1/robot-sequence` | `profile`、可选 `start/base_pose`、`segments`，可选参考结构签名 | 按阶段连续执行关节与轮速运动学；同一急停与状态版本联锁 |
| `POST /v1/robot-sine` | `profile`，`joints`（活动关节名列表），可选 `start`、`amplitude_deg`、`period_s`、`cycles`、`base_pose` | 正弦轨迹、实际振幅、限幅关节、峰值速度与静态重力 |
| `POST /v1/workbench-active-profile` | 完整参数配置 | 保存版本并原子替换当前配置指针；`workbench_applied=true`，真机 `runtime_applied=false` |
| `GET /v1/workbench-active-profile` | 无 | 当前配置、版本和急停状态；尚未写入时 `profile=null` |
| `GET /v1/workbench-state` | 无 | 当前配置编号、急停状态和 `motion_epoch` |
| `POST /v1/workbench-stop` | `engaged=true`；解除为 `engaged=false` 且提供 `expected_epoch` | 急停锁存/手动解除后的状态 |
| `POST /v1/robot-profiles` | 既有完整参数请求 | 不可覆盖的配置编号 |
| `GET /v1/robot-profiles/{id}` | 无 | 校验摘要后返回完整原配置 |

所有写请求使用 `Content-Type: application/json`，请求体上限 2 MiB。新增基座位姿字段省略时为零位，既有调用保持兼容。基座 X/Y/yaw 与关节角使用相同的 smoothstep 插值，不自动取转向最短路径。编辑器中的关节目标、夹爪开合、底盘目标与播放时长是本次试跑设置，不属于已保存的硬件配置；配置保存包含机器人 ID、URDF 和驱动参数。

五个运动接口省略 `profile` 时，使用已经写入的程序当前配置。计算前后都检查急停与状态版本，防止旧计算结果越过新的急停或配置切换。配置指针保存于服务 `--store` 目录的 `workbench-active.json`，被引用的历史版本继续保留；非法写入不会替换旧配置。
