# 统一工作台 0.3.0：导航与双臂操作

Ubuntu x86_64 自包含程序接入已有 nav3d_native 导航内核和平台命令联锁。支持差速轮与全向轮；不需安装 ROS 2。原 0.2.0 的双臂/腰部 runtime.2 内核及碰撞检查继续使用。

## 操作

1. 导入客户 URDF 与参数，设置十五关节和两个 TCP 映射。
2. 在“底盘导航”选择差速轮或全向轮，设置速度上限、转速与安全余量，填写地图坐标目标及朝向。
3. 通过“导航参数与地图”设置地图范围、原点和分辨率。未提供 data 时为合成空地图；导入实际栅格时 data 按行排列，长度为 ceil(size_x/resolution)×ceil(size_y/resolution)，仅整数 0 为自由空间，-1 与其他占用值均拒绝穿越。最大 40000 格，地图边长不超过 40 m，底盘世界坐标限制在 XY ±100 m。原手动底盘试跑仍限制在 XY ±5 m。
4. 在“客户规划配置”填写环境 box 障碍物。导航与双臂规划共用这些世界坐标障碍物，导航保守投影到 XY，不穿越任何高度的 box。停车后自动衔接的双臂规划也逐样本检查导航地图边界和占用/未知格，栅格区域保守视为全高度障碍柱。
5. 点击“导航到目标”，或设置双臂共同 X/Y/Z 位移后点击“导航到位后双手共同移动”。三维视图和小地图显示路径、障碍物与当前底盘位姿。

差速运动学只输出纵向速度与角速度；全向运动学可输出横向速度。URDF 中显式声明的四轮差速参考轮轴可以跟随动画。全向轮的厂家轮型、轮数、轮速分配、悬架/被动脚轮不作假定，本版不生成全向轮轴或电机命令。整机平面避障包络由当前 URDF 所有碰撞包围盒（无 collision 时使用 visual）的全部角点计算，包含展开双臂，另加客户安全余量；并非仅使用底盘尺寸。质量、惯量、电机标定不参与本版几何导航。

## 停车与取消

导航到位要求位置误差 ≤ 0.035 m、朝向误差 ≤ 2°。在几何仿真中，同时观测零命令与零位姿变化连续至少 0.6 秒后，服务器才提交双臂共同位移规划；其底盘位姿固定为刚确认的停车位姿。规划成功后页面播放已验证路径。

导航、对齐、停车与双臂规划期间，服务器拒绝其他运动请求。急停、取消、应用新参数会取消任务；页面停止轮询超过三秒或仿真更新中断超过 0.5 秒也会停止，不继续双臂操作。复位不自动恢复。失败只报告原因，不播放部分路径。

沿用的 A* 内核会宽松清除目标安全带并允许对角切角。新适配器预先拒绝起终点被占用、未知区域与地图边界；在调用原 A* 后补充路径包络检查及可通行的直角中间点。原 pure pursuit 的 22 cm 停止阈值由精确最终接近和朝向对齐补充。每步运动也检查整机包络，不因路径跟踪切弯而略过碰撞。

## 软件接口

| 接口 | 用途 |
|---|---|
| GET /v1/navigation-config | 支持底盘类型与默认配置 |
| POST /v1/navigation-start | profile/start/base_pose/goal/config/mapping/obstacles，可选 manipulation.translation_m |
| GET /v1/navigation-task/编号 | 持续轮询任务、仿真位姿、路径、速度和停车确认；亦维持页面连接 |
| POST /v1/navigation-cancel | task_id；取消导航及其自动提交的双臂规划 |

## 验收范围

本版是已接入现有导航算法的几何仿真工作台。定位来自确定性的几何仿真，不是传感器定位；未打包 FAST-LIO、激光驱动、ROS 2 节点或独立 C++ PRM/NMPC 程序。导入地图不等于现场地图标定。软件零运动确认不等于物理制动保证，实机底盘通信、定位质量、轮型运动学标定与独立急停仍待现场验收。动力学和 Windows 继续后续升级。
