## 交付边界

该验证是**关节运动学、给定底盘平面位姿与静态重力估算**，不是碰撞、平衡、完整动力学或实机验收。底盘位姿没有轮速解算、打滑、轮地接触或导航；不自动联动四个轮轴。Mesh 文件尚不加载，显示关节骨架并提示。惯量、阻尼和摩擦只校验保存，不参与当前运动积分。ROS 2 配置激活、运动控制适配及正式客户发行包仍待完成。本次不修改公开 Release 或标签。
