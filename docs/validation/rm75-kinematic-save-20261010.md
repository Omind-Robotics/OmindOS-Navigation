## 本轮已完成的增量

工作台后端新增显式 `profile_mode: "kinematic_preview"` 配置模式。通过现有 `/v1/workbench-active-profile` 接口，可以保存运动学配置并在服务重启后恢复；无需为未确认的质量、惯量、电机方向、编码器零位或力矩填写占位数值。

- 模式必须显式选择，未标注或错误模式仍进入原有严格校验。
- `dynamics` 可以省略；包含电机草稿时，字段和关节名称仍受检查，未知量允许保持 null。
- 配置按 SHA256 保存版本，完整文件写入后才发布版本路径；同一配置幂等、旧版本保留、读取验证完整性。
- 原有完整参数配置的内容和摘要规则不变；原 `robot_parameter_api.py`、ROS 参数加载器和设备接口未改动。
- 运动学配置不会被原严格运行时加载器接受，不会开启驱动；保存不解除已接合的软件停止状态，不续跑旧动作。
- 此增量只覆盖后端配置存取，不是完整的运动学运动接口升级。UI 模式选择、按编号读取运动学历史版本、点动/正弦运动与整机 CAD 接入仍待联调。不要将新模式设为默认配置或直接替换已发布安装包。
