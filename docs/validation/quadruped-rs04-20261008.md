# RS04 驱动与四足闭环验证记录

日期：2026-10-08。仅开发预览。目标电机根据用户截图更新为 ROBSTRIDE04；没有执行真实电机测试。

## 已通过

- 57 项 Python 测试：既有 30 项回归 + 27 项新测试。覆盖协议端点/中值字节、六个故障位、主机/总线身份、超时参数回读、缺少电机/标定、NaN 整批拒绝、外部传动比与方向、断流与超期停止、单总线失败仍尝试停止其余电机、控制故障锁存、旧会话与过期 arm 拒绝。
- 4 个浮动机身 MuJoCo 场景，每场 18.1 秒，共 72.4 秒仿真。使用与运行进程相同的 Controller/Sensors 接口和固定策略，200 Hz 动力学、50 Hz 推理。模型和执行器限幅均为原版 MEVIUS2 RS03 基准。
- ROS 2 Humble 容器中的 15 项端到端检查。ROS_DOMAIN_ID=219、ROS_LOCALHOST_ONLY=1；容器不挂载硬件设备，不赋予 CAN 配置权限；控制进程仅运行 mujoco 后端。

每场包含 1 秒待机、3.1 秒起身、3 秒站立、6 秒测试和 5 秒停止。验收门槛显式保存在脚本：策略阶段机身高度 >0.2 m、直立余弦 >0.8、停止末秒平均速度 <0.15 m/s，并检查前行/横移/转向量。上述是有限场景功能验证，不是客户指定的跟踪精度或稳定裕量验收。

## ROS 2 实际联调

通过项目：启动未使能、使能前禁止行走、显式使能、起身、站立高度、旧时间戳拒绝、显式行走、前向移动、速度断流后零速站立、恢复消息不自动继续、显式恢复、操作停止、急停、急停锁存、真实 DDS 传感器流。

最终通过运行收到 708 条 status、708 条 JointState 和 708 条 Imu。6 秒前行 x 位移 0.970 m，行走期间最低直立余弦 0.9855。JSON 记录保留实际结果；不是以单元测试或模拟 rclpy 替代 ROS 2。

首次 ROS 2 启动发现节点保留属性 `services` 命名冲突，改为 `command_services` 后重跑全链路通过。首次本地回归的 HTTP 检查因临时目录遗漏 web 资源失败，补齐相同基线资源后 57 项回归全部通过。

## 尚未验收的边界

RS04 真实固件/总线、USB 适配器的 Linux 驱动、真实零点与 IMU 安装、RS04 替换后的整机质量/惯量、上电/断电/硬急停行为、真实地面行走和热负荷均未实测。没有把购物车型号作为型号之外的实机证据。原版模型结果不能证明更换电机后的实机适用。

该增量未修改已发布的预览包，也未将固定基座三维调参页冒充动力学界面。开发 PR 依赖前面的 ROS 2 关节预览分支；其他对话的 UI 改动保持在其分支中。
