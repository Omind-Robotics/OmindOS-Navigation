## 复现

```bash
python3 -m unittest discover -s tests -v
python3 scripts/robot_workbench.py --store ./robot-configurations --port 8085
# 可选，另行安装 MuJoCo/NumPy：
python3 scripts/check_mda1_mujoco.py --output mujoco-check.json
```

浏览器选择“加载双七轴移动机器人”，点击“播放连续演示”。既有保存配置不会被自动覆盖；需要用户明确点击“将以上参数写入程序”才切换当前配置。
