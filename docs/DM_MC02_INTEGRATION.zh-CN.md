# DM-MC02 接入记录（开发预览）

2026-10-08 用户确认控制板型号为 **DM-MC02**。本记录确定接入方向，尚未提供可刷写固件或可用硬件适配器。仿真继续使用原版 MEVIUS2；RS04 实机驱动与客户整机步态、平衡仍待验收。

## 设备与证据

采购截图中的 Jetson ORIN NX 16GB Super 为拟用上位机；两套 mid-360-S 雷达和两套 Gemini336L 深度相机为采购记录。具体安装、载板、系统版本、供电、传感器位姿及时间同步尚未确认。数量、截图价格与合计 21,097 元保存在客户配置记录中；这不是当前市场报价，也不代表已到货或已接入。

DM-MC02 的厂商说明书 V1.1（2025-07-23，第 1–2 页）列明 STM32H723VGT6、三路 CAN FD、USB 和 BMI088；第 5 页说明 USB 为全速接口。板载 BMI088 目前仅是可选反馈来源，尚未确认为整机姿态传感器，安装方向和标定未知。

## 拟定职责

| 部件 | 职责 |
| --- | --- |
| Jetson 上位机 | 策略生成带关节名称的目标角度（rad），消费关节与机身反馈；保持通用接口 |
| DM-MC02 固件 | 接收完整角度批次，校验会话、序号和时效；按已标定方向、零点与外部传动比映射；编码 RS04 CAN 报文，回传反馈；执行本地看门狗与停机逻辑 |
| RS04 关节模组 | 在经确认的工作模式和限制参数下执行关节闭环；报告位置、速度与故障 |

用户已确认通过 USB 连接上位机与板卡；USB CDC 为当前候选实现，具体线协议仍待实现。这是项目接入选择，不是厂家预装协议。机内 `omindos.joint_position.v1` 的 JSON 契约也不是板卡现成报文。

按当前通用角度方案，无须在 DM-MC02 再做一层“角度转力矩”计算。若选择 RS04 运控模式，由板卡组装目标位置、目标速度、Kp、Kd 和前馈力矩等字段，闭环在关节内部执行；若选择 CSP，则按该模式发送位置及速度/力矩等限制配置。具体模式、固件与参数需确认，不能把两种模式视为等效，也不能把仿真 Kp/Kd 直接当作实机参数。

## 三路 CAN 规划与频率

用户确认 12 个关节先按三路 CAN、每路 4 个规划：

| DM-MC02 总线 | 规划关节数量 | 具体关节与线束分配 |
| --- | --- | --- |
| CAN1 | 4 | 待确认 |
| CAN2 | 4 | 待确认 |
| CAN3 | 4 | 待确认 |

这是容量规划，尚未分配具体关节。客户记录中此前两路各 6 个的 `can0/can1` 提案已清空，保留版本历史；电机 ID 仍是待核对的提案。这里的 CAN1/CAN2/CAN3 指板卡总线，不是 Jetson 的 SocketCAN 设备名称。

实机下发频率、反馈频率和实际波特率保持待定。先确定电机工作模式、每轮命令/反馈/参数访问的帧数，再核算每路总线的报文开销、仲裁与重传余量、USB 批次传输及 MCU 调度预算；随后实测延迟、抖动、反馈时效和故障停止时间，确定频率。不能只按数据区字节数估算，也不能由关节数量直接承诺频率。

现有 `control_reference` 的策略 50 Hz、仿真与目标下发 200 Hz 属于原版 MEVIUS2 仿真参考，不是三路 CAN 的实机验收值。配置记录中的 `can_bus_plan` 保存本次规划，具体硬件频率为 `null`，不会据此自动开启硬件。

## 剩余开发与验收

1. 固定 USB 帧格式、配置握手、协议版本、整批完整性校验、状态与故障反馈。跨主机和 MCU 的时间戳须处理时钟差与在途年龄，不能收到旧包后重新计时使其有效。
2. 实现板卡接收状态机和 RS04 扩展帧收发，使用能容纳 29 位 ID 的类型；明确经典 CAN/FD、波特率、滤波、收发缓冲区及多总线映射。厂商示例仅作外设参考。
3. 实现断流、过期、重放、故障、复位与掉线后的停止及锁存；明确电机自身通信超时与板卡停止动作。USB 重连或新角度不得自动使能。
4. 在电机不使能条件下先核对协议、固件版本和反馈，再完成单关节方向/零点/限位、停止行为及整机步态与平衡验收。软件报文验证不代替实机验收。
