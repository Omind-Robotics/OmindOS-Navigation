# 四足机器狗 V1.1：关节轴、零位与运动映射

本轮在 PR #22 的 954 个 CAD 零件实例上加入关节几何预览。识别 12 根驱动轴，开放 6 个已通过本轮几何检查的运动轴：四腿侧摆，以及左后腿的大腿、膝驱动。其余 6 轴显示轴线但锁定运动。原 STEP 与 GLB 均未修改；没有合并、公开发布或更新 Ubuntu 安装包。

## 运动关系与零位

- 预览零位为 STEP 保存姿态，界面显示的是相对此姿态的角度增量，**不是电机编码器零位**。
- 侧摆绕电机/轴承座共同轴线；大腿绕第二驱动轴；第三驱动与大腿轴同轴，通过摇臂和传动杆驱动小腿。
- 预览模型中，摇臂相对机身侧摆架的转角增量为“大腿角 + 膝驱动角”。小腿与传动杆的转角通过两圆交点求闭合解，保持源 CAD 分支，不使用独立摆动假装闭合。
- 轴正方向按显示箭头的右手定则。电机正反方向、编码器偏置、机械限位均为 `null`，未生成可下发给实机的映射。
- 侧摆 ±10°、大腿与膝驱动 ±20°仅为本地预览范围，不是厂家机械限位，不表示这些角度已通过干涉或安全验收。
- 界面支持逐腿角度调节、五视角、轴线显示、恢复 CAD 零位和 6 秒小幅预览。停止、离开 CAD 页、切换后台、窗口失焦或 Esc 都会停止动画；不会自动恢复运动。
- 超范围、非有限数、被锁定轴和无闭合解请求，在改变任何零件前拒绝，保留上一姿态。

## 绑定范围与限制

766 个腿部实例被划分到机身固定、侧摆架、大腿、摇臂、小腿、传动杆组，所有实例恰好归属一组。电机内部零件跟随其壳体，不单独模拟齿轮或转子内部运动。199 个紧固件/小附件通过邻近 CAD 包围范围暂定归属，尚未完成全部装配配合的人工确认；记录在 `provisional_fastener_attachments` 中。因此本轮是**带装配问题保护的几何预览**，不能作为全装配运动验收。

没有计算精确碰撞、接触力、重心稳定性、质量惯量或步态。CAD 页不发送控制运动请求，不替换当前 URDF/控制配置；原参数页保留其参考模型与未保存草稿。

## 数据与复现

- `config/robot_models/originmind_quadruped_v11/kinematics.json`：轴线、零位约定、闭合点、零件组、锁定原因与源错位尺寸。
- `joint_evidence.json`：用于轴线提取的原实例名称与解析圆柱面记录。
- 数据同时绑定原 STEP 和 GLB 的 SHA-256；模型版本不符时拒绝加载运动。
- 生成工具与 CAD 依赖仅用于开发，客户工作台读取预生成 JSON。

```sh
python scripts/build_quadruped_kinematics.py /absolute/path/四足机器狗总装V1.1.STEP
node web/robot-workbench/build-renderer.cjs
node scripts/check_quadruped_kinematics.cjs docs/validation/quadruped-v11-motion/KINEMATICS_VALIDATION.json
# WORKBENCH_ROOT 指向 quadruped_variant.prepare 生成的本地四足工作台目录
WORKBENCH_ROOT=/absolute/path/to/prepared-workbench node scripts/check_quadruped_cad.cjs docs/validation/quadruped-v11-motion
python -m unittest tests.test_robot_workbench tests.test_robot_parameter_api
```

几何检查：7 类检查、1,332 组开放角度采样通过；采样后连接孔轴线最大数值残差约 `1.01e-11 m`。这只是所定义几何模型的数值闭合误差，**不是制造精度，也不抵消源装配错位**。检查覆盖零位还原、固定机身、全腿实例唯一归属、闭合轴线、不完整装配锁定、非法输入和原子拒绝。

浏览器检查：Chromium 153 / SwiftShader 下 20 项通过，包括实际 CAD 渲染像素随姿态变化、6 轴开放与6轴锁定、停止/归零/切页停止、原参数页草稿及配置保持和 390px 手机布局。零 JS 异常、零意外资源失败、零运动请求。原工作台/参数接口 31 项测试通过。结果 JSON 与预览图位于 `docs/validation/quadruped-v11-motion/`。

下一步应核对两条前腿摇臂、修正右后摇臂的装配配合，确认紧固件归属，再开放完整 12 轴，开展全行程干涉检查及实机方向、零位、限位标定。Ubuntu 安装包待这批模型问题处理后更新。
