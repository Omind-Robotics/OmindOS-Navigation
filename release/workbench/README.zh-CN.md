# OmindOS 机械臂统一工作台 0.2.0

Ubuntu 版，统一三维调参、双臂与腰部规划和离散碰撞检查。动力学与 Windows 新版后续升级。

新“规划”入口使用 runtime.2 的同一协同内核，直接读取当前客户 URDF、限位与 TCP。
关节路径规划使用有界 RRT-Connect；双手共同位移保持两手相对位姿。可导入导出规划映射与环境障碍物。
详细操作和验收范围见随包 `PLANNING.zh-CN.md`。

preview.8 加载 RM75-B 厂家原始 STL：八个网格在左右机械臂共显示十六个实例，保留原关节结构、质量和惯量。参考用户外观图改善白橙配色、材质、灯光、阴影和观察视角；加入 35 秒双臂协同、双夹爪独立开合及底盘与机械臂连续运动预览。保留 preview.7 的 16 px 主文字、至少 14 px 说明文字与手机布局。

本次只发布 Ubuntu x64 包；Windows 新版延后。preview.7 的 Windows/Linux 包继续保留。

本版统一包含 PR #2 的工作台与二指夹爪、PR #3 的 ROS 2 预览界面与本机桥接、PR #6 的设备通信配置。与 preview.4 相比，桌面程序现在支持 `--runtime-url`，可连接独立运行的本机 ROS 2 预览服务。完整 ROS 2 节点未捆绑进桌面小包，使用方式与验收范围见 `ROS2.zh-CN.md`。

## 打开程序

下载与电脑系统对应的压缩包，并完整解压。不要只移动其中的可执行文件，保留同目录的运行库和资源。

- Ubuntu x64（22.04 或更新兼容系统）：在解压目录打开终端，执行 `./OmindOS-Workbench`。

**无需安装 Python、ROS、Node.js 或 Docker。** 需要现代浏览器；三维实体显示使用 WebGL，无法使用时回退线框。网页资源均在本机，运行无需联网。

程序会尝试自动打开 `http://127.0.0.1:8085/`。如果浏览器没有自动打开，手动访问该地址。保留程序终端窗口，结束时按 Ctrl+C。端口被占用时，在终端给启动命令加 `--port 8086`，然后访问显示的新地址。仅支持本机使用。

本次提供 Ubuntu x64 可执行包；不包含 Windows 新版、手机、macOS 或 ARM 版本。

## 开始试用

点击“加载双七轴移动机器人”，修改参数后点击“将以上参数写入程序”。可进行关节 ±0.1° 点动、单臂/双臂/主体关节正弦，以及底盘前进、后退、左右转向和停车。

点击“播放连续演示 · 35 秒”观看连续动作，可展开三维视图、跟随底盘、观察左右夹爪和工具轨迹。演示使用现有参考关节结构；客户修改关节安装位置或轴方向后，可重新编写并验证相应动作。旧配置不会自动升级厂家网格，需要重新加载并写入新版参考模型。

左侧“设备通信”可分别选择左右 RM75、Elmo 腰部和 DT-01 Pro 底盘的通信方式。先留为“待选择”或留空参数也能保存；切换方式保留之前填写的内容，左右臂地址独立。通信设置随参数版本保存，重启、导出和重新导入均可恢复。所有通信方式目前仅保存配置，驱动未接入，不会建立连接或发送真机指令。

左右臂各七轴，加腰部俯仰共十五个主体关节；夹爪与四轮轴单独控制。底盘是四轮差速参考模型，轮型与尺寸仍须按实际设备确认。全身正弦只涵盖十五个主体关节。

DT-01 Pro 资料为双轮差速及前后脚轮；选择该设备的通信配置不会自动改变参考模型的轮型。MQTT 是资料中的导航接口，Modbus 为待确认扩展；Elmo 的 CANopen/EtherCAT 版本和串口电平、RM75 控制器与 SDK 版本均须按实物确认。

停车与急停保持当前显示位置。“复位”只解除急停，不归零、不自动续跑；重新运行需再次操作。

配置保存在当前用户目录下的 `OmindOS/workbench-configurations`，不随升级解压而删除。可用 `--store "指定目录"` 改变保存位置。旧配置不会自动升级；需要新版参考模型时重新加载并写入参数。

## 发行范围

本包不附带 Python 后端业务源码、开发测试、构建脚本或前端源映射。后端编译为本机程序；浏览器端 HTML、CSS、JavaScript 和模型参数仍可查看。编译发行不代表不可逆向。

本版“规划”入口包含固定底盘运动学、路径规划及几何包围盒的保守离散碰撞检查。原有点动、正弦、连续演示、底盘试跑和 ROS 预览仍为运动学功能。相邻两个主体关节及固定装配内部采用结构性碰撞排除；跨臂保持检查。不验证连续碰撞、载荷实体、接触、侧滑、平衡、动力学或实际驱动控制。六秒动画仅为播放速度。界面急停属于软件联锁，接真机需适配驱动并另行验收。

客户可通过 URDF 与参数编辑，按硬件设置安装尺寸、关节结构、质量/惯量、驱动参数和通信选项，并保存为独立配置。内置双指夹爪与四轮差速底盘采用参考配置，可根据客户机构替换模型；参考值不代表所有客户设备。

MuJoCo 3.3.7 已在独立开发环境完成固定底座、禁用接触的导入、惯量与静态重力一致性检查，未捆绑进本安装包。抓取接触、轮地摩擦与动态平衡属于后续动力学功能，当前演示未进行这些计算或真机运行验证。

`MANIFEST.json` 记录版本、文件校验摘要和构建信息；启动器会检查包完整性。命令行加 `--verify` 可单独校验并退出。`VALIDATION.json` 记录该平台可执行包的启动与接口验收结果。

“ROS 2 保存并加载 / 试运行 / 停止”需要另行启动同一配置目录对应的 ROS 2 预览服务，并向工作台传入 `--runtime-url http://127.0.0.1:8086`。未配置或服务未启动时会明确显示未连接；本机调参、夹爪开合和运动学动画仍可使用。ROS 2 加载成功仅表示预览节点已加载，不表示真机驱动已接通。

第三方许可证保留在 `LICENSES/` 和模型说明目录。已有导航运行包继续保留在 [0.2.0-preview.2](https://github.com/maganrobotics-boop/OmindOS-Navigation-Release/releases/tag/v0.2.0-preview.2)，本包不包含该导航 Docker 镜像。
